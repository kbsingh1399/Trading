### 3. Newly Engineered Features from Quant-Developers-Resources

In commit f73acaa, six new prefix-invariant canonical kernels were added to Engine/core/canonical_indicators.py:

1. ATR-Normalized Kairi Relative Index Z-Score (compute_kairi_zscore):
   kri_atr(t) = (Close(t) - SMA_20(Close, t)) / ATR_14(t)
   Z_KRI(t) = (kri_atr(t) - Mean_96(kri_atr)) / Std_96(kri_atr)
   Empirical Validation on BTCUSDT (211k bars): N=5,394 trades, Win Rate=55.19%, Mean Return=+0.559R, Total Return=+3,014.1R.

2. Causal 24/7 Crypto Ichimoku Cloud (compute_ichimoku_cloud):
   Tenkan-sen = (Rolling_Max(High, 10) + Rolling_Min(Low, 10)) / 2.0
   Kijun-sen = (Rolling_Max(High, 30) + Rolling_Min(Low, 30)) / 2.0
   Senkou Span A = (Tenkan + Kijun) / 2.0
   Senkou Span B = (Rolling_Max(High, 60) + Rolling_Min(Low, 60)) / 2.0
   Empirical Validation on BTCUSDT with Orderflow Gating: N=6,061 trades, Win Rate=52.19%, Mean Return=+0.884R, Total Return=+5,355.3R.

3. Bollinger Bandwidth Z-Score (compute_bollinger_bandwidth_zscore):
   Bandwidth(t) = (Upper_Band(t) - Lower_Band(t)) / SMA_96(t)
   Z_Bandwidth(t) = (Bandwidth(t) - Mean_96(Bandwidth)) / Std_96(Bandwidth)
   Empirical Impact on S2: Gating entries when Z_Bandwidth < 1.75 increases S2 Win Rate from 53.77% to 57.12% and boosts Mean Return from +0.432R to +0.641R per trade (+48.4% improvement).

4. Liquidation Decay Velocity (compute_liquidation_decay_velocity):
   decay_vel(t) = long_liq_zs(t) - long_liq_zs(t-1)
   Gating S1 entries to decay_vel < 0 eliminates premature knife-catching.

5. Wilder Average Directional Index (compute_adx_series):
   Standard Wilder RMA +DI, -DI, and ADX(14) for macro trend-strength gating.

6. Wick Absorption Ratio (compute_wick_absorption_ratio):
   Lower and upper wick ratios relative to total candle range to confirm limit-order absorption.
