### Key Remediation Details:

1. **Causal Data Availability Parity (Eliminating the Double-Lag)**:
   - In `Engine/core/strategy_kernel.py`, replaced the trim-and-shift lag with causal availability timestamp offsets:
     * Daily bars: `bd_avail = pd.DataFrame(index=bd.index + pd.Timedelta(days=1))`
     * 4H bars: `b4h_avail = pd.DataFrame(index=b4h.index + pd.Timedelta(hours=4))`
   - Bars are joined causally via `pd.merge_asof(direction='backward')`. A 15m bar on day T sees the completed high/low of day T-1 as soon as day T begins (00:00 UTC), without double-lagging into day T-2.
   - `Engine/forex_engine.py` delegates feature computation directly to `strategy_kernel.compute_features_pandas()`, guaranteeing exact feature parity across live and backtest engines.

2. **Execution Barrier & Safety Guards (`OrderManager`)**:
   - Added `dry_run: bool = False` execution barrier to `OrderManager.__init__`.
   - In dry-run mode, order placement, position closing, and SL modification log and track state internally without invoking `mt5.order_send`.
   - All `mt5.order_send` return values are verified with `result is None or getattr(result, "retcode", None) != TRADE_RETCODE_DONE`.
   - `calculate_lot_size()` clamps to 0.0 if `sl_dist <= 0`, `raw_lots < volume_min`, or symbol specs are missing.

3. **Inference Engine & Quarantine Hardening (`StatefulInferenceEngine`)**:
   - `check_quarantine()` now validates `atr is None or spread is None or not np.isfinite(atr) or not np.isfinite(spread) or atr <= 0 or spread <= 0`, failing safe to quarantine.
   - Hysteresis recovery counter requires 2 consecutive *unique completed 15m bars* (`bar_time != self._last_quarantine_bar`) to exit quarantine, preventing intra-bar multiple call artifacts.
   - Wires `refresh_4h_buffer()` on every new completed 15m candle.

4. **Spread Friction & State Persistence (`ForwardState`)**:
   - Clean single-tick executable fills: entry at ask (BUY) / bid (SELL); exit at bid (BUY) / ask (SELL). Spread is embedded in executable fill prices (`spread_already_deducted=True`).
   - Drawdown metrics persist across process restarts via `lifetime_max_dd_ratio` and `lifetime_max_dd_usd`.
   - Mark-to-market equity including unrealized PnL is computed via `get_marked_equity()`.
   - Risk governor evaluates mark-to-market drawdown and unlocks House Money ($50 USD) when net profit > 100 USD and DD < 1.0%.
