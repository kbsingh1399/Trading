```python
import os
import glob
import pandas as pd
import polars as pl

def load_symbol_data(symbol: str, data_dir: str = ".") -> pd.DataFrame:
    # Check for split parts first
    parts = sorted(glob.glob(os.path.join(data_dir, f"{symbol}_15m_master_2020_2026_part*.parquet")))
    if parts:
        dfs = [pd.read_parquet(p) for p in parts]
        df = pd.concat(dfs, ignore_index=True)
    else:
        single = os.path.join(data_dir, f"{symbol}_15m_master_2020_2026.parquet")
        df = pd.read_parquet(single)
    
    df = df.sort_values("open_time_ms").drop_duplicates(subset=["open_time_ms"]).reset_index(drop=True)
    ts = pd.to_datetime(df["open_time_ms"], unit="ms", utc=True)
    df["date_int"]   = (ts.dt.year * 10000 + ts.dt.month * 100 + ts.dt.day).astype("int32")
    df["hour_int"]   = ts.dt.hour.astype("int32")
    df["minute_int"] = ts.dt.minute.astype("int32")
    df["dow_int"]    = ts.dt.dayofweek.astype("int32")
    return df
```

4. SETTLED STRATEGY INVARIANTS & MICROSTRUCTURE RATCHET
================================================================================
- Causal Execution: Opening Range is measured across `range_duration_bars = 2` (30 minutes). Breakout bar `j` must close outside the range. Fill occurs strictly at `opens[j+1]` (the open of the subsequent bar).
- Enforced 1:3 RR: Take profit is set at exactly `entry + 3.0 * r_val` (long) or `entry - 3.0 * r_val` (short).
- Microstructure Ratchet:
  * Phase 0 (BE Lock): At +0.8R gain, move stop to `entry + 0.35R` (guarantees net positive PnL clearing 41 bps friction).
  * Phase 1 (Profit Lock): At +1.5R gain, move stop to `entry + 0.80R` and unlock dynamic trailing SL.
  * Dynamic ATR Trailing Stop: Trailing stop trails at `closes[k] - 1.5 * ATR` (long) or `closes[k] + 1.5 * ATR` (short). Computed on close of bar `k`, evaluated against bar `k+1`. Stop never moves backwards.
  * Time Decay: Exit at market after 24 bars (6 hours) if trade gain is < +0.2R.
- Friction Model: Calibrated 0.08R flat deduction per completed trade.
- 72-Hour Causal Purge: In-sample training cutoff is strictly `window_start - 72 hours`.
