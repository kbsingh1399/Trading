2. ECONOMETRIC FOUNDATIONS FROM SSRN-5020002 (ORDER FLOW & CRYPTO RETURNS)
================================================================================
SSRN-5020002 establishes 4 pivotal empirical laws across 82 cryptocurrencies and 11 currency quote centers:

1. Transitory Reversal vs Permanent Price Impact (The Orthogonalization Mandate):
   - Problem: Raw order flow (signed volume difference) has two opposing forces:
     a) Transitory component: correlated with short-term returns (noise trading, bid-ask bounce, inventory bounce) that strongly reverses.
     b) Permanent component: uncorrelated with short-term returns (private information, adverse selection, institutional inventory shifts) that persists.
   - Result: In daily regressions, raw order flow alone is insignificant (t-stat = 1.56, Sharpe = -0.12). When controlling for lagged returns (or recursively orthogonalizing order flow against lagged returns: ortho-OFW), the t-statistic jumps to 5.54 and the annualized Sharpe ratio surges to +1.34!
   - Implementation: Compute `ortho_of_{i,t}` as the residual from a recursive expanding regression of order flow on lagged return:
     `of_{i,t} = alpha_{i,t} + beta_{i,t} * r_{i,t} + epsilon_{i,t}`
     The residual `epsilon_{i,t}` isolates pure permanent informational order flow.

2. Non-Linear Feature Interactions & Robust Huber Loss (The SGB Superiority):
   - Empirical Proof: Linear models (OLS, Ridge, Lasso, Elastic Net, PCR) fail out-of-sample with negative R2_oos (OLS R2_oos = -1.24%). In contrast, non-linear Stochastic Gradient Boosted Trees (SGB) achieve R2_oos = +0.66% and an annualized Sharpe ratio of 3.63 in Long-Short (P5 - P1)!
   - Loss Function Invariant: Crypto returns exhibit extreme kurtosis and heavy tails. Estimating models with L2 (MSE) causes severe overfitting to liquidation spikes. The robust Huber loss function:
     `H(x; xi) = x^2` if `|x| <= xi`, else `2*xi*|x| - xi^2`
     with threshold `xi` set at the 99.9th percentile of training returns, dramatically stabilizes out-of-sample calibration.

3. Long-Short Sorting as Drawdown Defense:
   - Long-only portfolio (P5) exhibits an annualized Sharpe ratio of 1.85 but suffers a Maximum Drawdown of 68%!
   - Long-Short quintile portfolio (P5 - P1) cuts Maximum Drawdown from 68% down to 29% (and Random Forests cuts MDD to 23%), while delivering 0.78% daily mean return (196% annualized) and an annualized Sharpe ratio of 3.63.
   - Break-even transaction cost is 0.51% (51 bps) daily, ensuring that real exchange taker frictions (8 to 10 bps) leave massive residual economic alpha.

4. Cross-Asset Information Aggregation (Systemic Market Order Flow):
   - Single-asset order flow contains high idiosyncratic noise. Aggregating order flow across assets (World Order Flow `OF^W`) and conditioning on relative order flow (`Rel_OF_{i,t} = OF_{i,t} - OF^M_t`) filters idiosyncratic liquidity shocks and isolates cross-sectional relative alpha.
